# TerraCurio Changelog

## 1.0.X — Latest

### New Accessories
- **Ram Rune** — Hold crouch in mid-air and press jump to slam downward. Landing creates an explosion that damages nearby enemies.

### Mechanic Changes
- **Flight system reworked** — Gliding wings now take priority over flying carpets.
- **Right-click delay reduction** now only applies to blocks (non-block items no longer benefit).
- **Fluid Walking Boots** now bounce submerged players to the surface.
- **Frostspark & Terraspark Boots** no longer break powder snow / thin ice. Step height bonus can be toggled in config.
- **Balloon accessories** (Red Balloon, Balloon, Pufferfish Balloon) each grant an extra +1 fall damage reduction.
- **Boot speed** can now be toggled per-player in config.

### Bug Fixes
- Fixed flight accessories not restoring after player death or dimension change.
- Fixed continuous flight accessories randomly stopping.
- Fixed some accessories losing effects after logout.
- Fixed info accessories (Radar, Metal Detector, Life Form Analyzer) using wrong detection range.
- Fixed diving helmet / farmland interaction.

### Visual
- Updated all accessory item textures.
- Added animated textures for Magma Skull, Molten Skull Rose, and Demon Heart.
- Particles on bottle accessories and speed boots now render correctly during reversed gravity.
- Magma Skull now glows properly at full brightness.

### NeoForge
- Updated to NeoForge 21.1.219.
